# Project Principles

Every feature should follow these principles.

1. Community First

Every decision should benefit community members.

2. Mobile First

Most users will use mobile.

3. Simple over Complex

Avoid unnecessary screens.

4. Transparency

Every financial transaction must be traceable.

5. Reusable Components

Never duplicate UI.

6. Accessibility

Easy for all age groups.

7. Offline Friendly

Design with intermittent internet in mind.

8. Multi Organization Ready

Never hardcode organization-specific data.

9. AI Friendly

Architecture and code should be easy for AI tools to understand and extend.

10. Performance

Keep the app fast and responsive, even on low-end Android devices.
