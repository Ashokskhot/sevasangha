# SevaSangha

SevaSangha is a modern Community Management Platform designed for villages, temple committees, youth clubs, NGOs, housing societies, and other community organizations.

The platform helps organizations manage:

- Members
- Committee
- Events
- Attendance
- Member Contributions
- Income & Expenses
- Gallery
- Loans (Future)
- Public Website
- Reports

## Technology Stack

- React Native (Expo)
- Next.js
- Firebase
- Firestore
- Firebase Storage
- TypeScript
- React Native Paper
- NativeWind
- GitHub
